# Foto galeri

Tambahkan foto kegiatan 7 KAIH SMAN 2 Cibinong yang sudah memperoleh izin
publikasi dengan nama berikut:

- `scene-morning.jpg` — pembiasaan bangun pagi/kesiapan belajar
- `scene-sport.jpg` — olahraga atau aktivitas fisik
- `scene-study.jpg` — kegiatan membaca atau belajar
- `scene-community.jpg` — kegiatan kepedulian dan kebersamaan

Foto disajikan dari browser sebagai aset publik. Pastikan foto tidak
menampilkan data pribadi yang tidak perlu dan gunakan dokumentasi yang memang
boleh dipublikasikan. Jika file belum tersedia atau gagal dimuat, kartu galeri
menampilkan latar ilustrasi gradien.
